现货 WebSocket API

基本信息​

连接地址​

环境地址
生产环境wss://ws.yourexchange.com/ws
测试环境wss://ws-testnet.yourexchange.com/ws
提示

请根据实际部署环境替换域名。

连接限制​

限制项值
单用户最大连接数5
单连接最大订阅数100
消息最大长度4KB
请求频率限制10 次/秒

频道类型​

类型说明是否需要认证
公共频道ticker、trade、depth、kline❌ 不需要
私有频道order、balance✅ 需要先认证

认证 Token​

私有频道需要 JWT Token 进行认证：

  • 获取方式：通过 REST API 登录接口获取
  • 有效期：24 小时
  • 格式：Bearer JWT Token
POST /api/v1/auth/login

请求报文格式​

客户端发送的所有请求采用统一 JSON 格式：

{
  "op": "<操作类型>",
  "args": ["<参数1>", "<参数2>", ...]
}
字段类型必填说明
opstring是操作类型：subscribe、unsubscribe、auth、ping
argsarray否参数列表

操作类型​

op说明args 示例
subscribe订阅频道["ticker@BTC_USDT", "trade@ETH_USDT"]
unsubscribe取消订阅["ticker@BTC_USDT"]
auth认证登录["<jwt_token>"]
ping心跳无需参数

响应报文格式​

服务端响应采用统一格式：

{
  "op": "<操作类型>",
  "success": true,
  "msg": "<错误信息>",
  "args": ["<已订阅频道>"]
}
字段类型说明
opstring对应请求的操作类型
successboolean是否成功
msgstring错误信息（失败时返回）
argsarray已成功订阅的频道列表

响应示例​

订阅成功：

{"op":"subscribe","success":true,"args":["ticker@BTC_USDT","trade@BTC_USDT"]}

订阅失败（私有频道未认证）：

{"op":"subscribe","success":true,"msg":"private channels require authentication","args":[]}

认证成功：

{"op":"auth","success":true}

认证失败：

{"op":"auth","success":false,"msg":"invalid token"}

推送报文格式​

服务端推送采用统一格式：

{
  "ch": "<频道名>",
  "d": { <数据内容> }
}
字段类型说明
chstring频道名称
dobject数据内容（各频道格式不同）

心跳​

客户端需定期发送心跳以保持连接，建议间隔 30 秒。

请求：

{"op":"ping"}

响应：

{"op":"pong"}
注意

超过 60 秒 未收到客户端消息，服务端将主动断开连接。

订阅参数​

频道格式​

公共频道采用 {channel}@{symbol} 或 {channel}@{symbol},{param} 格式：

频道格式示例
Tickerticker@{symbol}ticker@BTC_USDT
成交记录trade@{symbol}trade@BTC_USDT
有限深度depth@{symbol},{level}depth@BTC_USDT,20
增量深度depth_update@{symbol}depth_update@BTC_USDT
K线kline@{symbol},{interval}kline@BTC_USDT,1m

私有频道直接使用频道名：

频道格式
订单order
余额balance

批量订阅​

支持一次订阅多个频道：

{
  "op": "subscribe",
  "args": [
    "ticker@BTC_USDT",
    "ticker@ETH_USDT",
    "trade@BTC_USDT",
    "depth@BTC_USDT,20"
  ]
}

支持档位： 5, 10, 20, 50, 100, 200, 400

订阅：

{"op":"subscribe","args":["depth@BTC_USDT,20"]}

推送：

{
  "ch": "depth@BTC_USDT,20",
  "d": {
    "s": "BTC_USDT",
    "u": 12345,
    "t": 1768205315166,
    "b": [
      ["48999", "1.5"],
      ["48998", "2.3"]
    ],
    "a": [
      ["49001", "0.8"],
      ["49002", "1.2"]
    ]
  }
}
字段类型说明
sstring交易对
unumberlastUpdateId（用于增量同步校验）
tnumber时间戳（毫秒）
barray买单 [[价格, 数量], ...]，按价格降序
aarray卖单 [[价格, 数量], ...]，按价格升序

增量深度​

深度增量更新，实时推送（无节流）。

重要

增量更新必须保持顺序，不能丢失任何消息，否则本地 Orderbook 会不一致。

订阅：

{"op":"subscribe","args":["depth_update@BTC_USDT"]}

推送：

{
  "ch": "depth_update@BTC_USDT",
  "d": {
    "s": "BTC_USDT",
    "U": 12345,
    "u": 12346,
    "t": 1768205315200,
    "b": [["48999", "0"]],
    "a": [["49001", "1.5"]]
  }
}
字段类型说明
sstring交易对
Unumber起始更新 ID（firstUpdateId）
unumber结束更新 ID（lastUpdateId）
tnumber时间戳（毫秒）
barray买单变更，数量为 "0" 表示删除该价位
aarray卖单变更，数量为 "0" 表示删除该价位

Orderbook 维护​

本地维护 Orderbook 推荐流程：

步骤​

  1. 订阅增量深度

    {"op":"subscribe","args":["depth_update@BTC_USDT"]}

  2. 缓存增量消息
    开始缓存收到的增量更新

  3. 获取深度快照

    {"op":"subscribe","args":["depth@BTC_USDT,400"]}

    收到快照后记录 lastUpdateId（快照中的 u 字段）

  4. 应用增量更新

    • 丢弃 u <= lastUpdateId 的增量消息
    • 找到第一个满足 U <= lastUpdateId + 1 且 u >= lastUpdateId + 1 的增量消息
    • 从该消息开始应用更新

  5. 持续更新

    • 后续增量消息：若 U == 本地lastUpdateId + 1，应用更新
    • 更新后：本地lastUpdateId = 增量消息的 u

  6. 断线重连

    • 若发现 U > 本地lastUpdateId + 1（有缺口），重新从步骤 1 开始

更新逻辑​

function applyUpdate(orderbook, updates) {
  for (const [price, quantity] of updates) {
    if (quantity === "0") {
      // 删除该价位
      delete orderbook[price];
    } else {
      // 更新或新增
      orderbook[price] = quantity;
    }
  }
}
建议

建议同时订阅 depth@{symbol},400 和 depth_update@{symbol}，定期用快照校验本地 Orderbook 的正确性。

私有频道​

认证要求

私有频道需要先发送 auth 请求完成认证，认证成功后才能订阅。

发送 Auth 登录​

请求：

{"op":"auth","args":["<jwt_token>"]}

成功响应：

{"op":"auth","success":true}

失败响应：

{"op":"auth","success":false,"msg":"invalid token"}

完整流程​

// 1. 建立连接
const ws = new WebSocket('wss://ws.example.com/ws');

// 2. 认证
ws.onopen = () => {
  ws.send(JSON.stringify({
    op: "auth",
    args: ["your-jwt-token"]
  }));
};

// 3. 认证成功后订阅私有频道
ws.onmessage = (event) => {
  const msg = JSON.parse(event.data);
  if (msg.op === "auth" && msg.success) {
    ws.send(JSON.stringify({
      op: "subscribe",
      args: ["order", "balance"]
    }));
  }
};

完整示例​

const ws = new WebSocket('wss://ws.example.com/ws');

ws.onopen = () => {
  console.log('连接成功');
  
  // 订阅公共频道（无需认证）
  ws.send(JSON.stringify({
    op: "subscribe",
    args: ["ticker@BTC_USDT", "trade@BTC_USDT", "depth@BTC_USDT,20"]
  }));
  
  // 认证（订阅私有频道前必须）
  ws.send(JSON.stringify({
    op: "auth",
    args: ["your-jwt-token"]
  }));
};

ws.onmessage = (event) => {
  const msg = JSON.parse(event.data);
  
  // 处理响应
  if (msg.op) {
    if (msg.op === "auth" && msg.success) {
      // 认证成功，订阅私有频道
      ws.send(JSON.stringify({
        op: "subscribe",
        args: ["order", "balance"]
      }));
    }
    return;
  }
  
  // 处理推送
  switch (msg.ch) {
    case "ticker@BTC_USDT":
      console.log("Ticker:", msg.d);
      break;
    case "trade@BTC_USDT":
      console.log("Trade:", msg.d);
      break;
    case "order":
      console.log("订单更新:", msg.d);
      break;
    case "balance":
      console.log("余额变动:", msg.d.a, msg.d.d);
      break;
  }
};

// 心跳
setInterval(() => {
  if (ws.readyState === WebSocket.OPEN) {
    ws.send(JSON.stringify({ op: "ping" }));
  }
}, 30000);

断线重连​

建议实现自动重连机制：

class WebSocketClient {
  constructor(url, token) {
    this.url = url;
    this.token = token;
    this.reconnectDelay = 1000; // 初始重连延迟 1 秒
    this.maxReconnectDelay = 30000; // 最大重连延迟 30 秒
    this.subscriptions = []; // 保存订阅列表
    this.connect();
  }

  connect() {
    this.ws = new WebSocket(this.url);

    this.ws.onopen = () => {
      console.log('连接成功');
      this.reconnectDelay = 1000; // 重置重连延迟
      
      // 重新认证
      if (this.token) {
        this.ws.send(JSON.stringify({ op: "auth", args: [this.token] }));
      }
      
      // 重新订阅
      if (this.subscriptions.length > 0) {
        this.ws.send(JSON.stringify({ op: "subscribe", args: this.subscriptions }));
      }
    };

    this.ws.onclose = () => {
      console.log(`连接断开，${this.reconnectDelay / 1000} 秒后重连...`);
      setTimeout(() => this.connect(), this.reconnectDelay);
      
      // 指数退避
      this.reconnectDelay = Math.min(this.reconnectDelay * 2, this.maxReconnectDelay);
    };

    this.ws.onerror = (error) => {
      console.error('WebSocket 错误:', error);
    };
  }

  subscribe(channels) {
    this.subscriptions = [...new Set([...this.subscriptions, ...channels])];
    if (this.ws.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify({ op: "subscribe", args: channels }));
    }
  }
}

// 使用示例
const client = new WebSocketClient('wss://ws.yourexchange.com/ws', 'your-jwt-token');
client.subscribe(['ticker@BTC_USDT', 'order', 'balance']);
重连建议
  1. 使用指数退避策略，避免服务器过载
  2. 重连后需要重新认证和重新订阅
  3. 对于 Orderbook，重连后需要重新获取快照
